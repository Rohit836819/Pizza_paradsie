🍕 Pizza Paradise

🌟 About the Project
Pizza Paradise is a modern and visually appealing frontend website designed for an online pizza ordering experience. The website focuses on delivering a smooth, user-friendly interface where customers can explore pizza varieties, add items to a cart, and place orders effortlessly.


## 🎯 Key Features
- Attractive and responsive user interface  
- Interactive menu with pizza categories  
- Add-to-cart and dynamic cart updates  
- Order summary and confirmation modal  
- Smooth navigation with modern UI elements  



## 🛠️ Technologies Used
- **HTML5** – Structure of the website  
- **CSS3** – Styling and responsive layout  
- **JavaScript** – Interactivity and cart functionality  
- **Font Awesome** – Icons  
- **Google Fonts** – Typography  



📄 Project Description
Pizza Paradise simulates a real-world pizza ordering website where users can browse the menu, view pizza details, manage their cart, and place orders. The design emphasizes simplicity, aesthetics, and usability, making it suitable for academic projects, frontend practice, and portfolio showcasing.



🚀 Purpose
This project was built to practice frontend development skills, user interface design, and client-side interactivity while creating a realistic food-ordering website experience.
